# Gate 1: Product

## User Problem

The owner cannot see MarketPulse narrow the NSE universe into evidence-backed opportunities or understand why securities were excluded.

## Desired Outcome

The owner opens `/scanner` and sees one reproducible funnel from verified NSE universe to bounded candidates. Every stage reconciles, every exclusion has a reason, and each candidate links to the exact evidence and downstream status. `/brain` shows the same run in one daily decision brief.

## Success Evidence

- Every current NSE listing reaches exactly one terminal result.
- Counts reconcile at every stage.
- Identical evidence and policy produce identical ordering.
- Missing history and unavailable inputs are explicit.
- No rejected security invokes model research.
- No scanner action mutates validation, holdout, forward, or paper evidence.
- Scanner and Brain display the same persisted run identity and payload hash.

## Non-Goals

- No live broker execution.
- No 133-agent organization.
- No peer-to-peer agent handoffs.
- No LLM-generated numerical market score.
- No generic agent framework in the first slice.

# Gate 0: Reality

## Confirmed Existing Capabilities

- STATICALLY_CONFIRMED: `runLearningCycle` is the single serialized manager under a cross-driver lease.
- STATICALLY_CONFIRMED: `/scanner` shows signals from already-authored strategies; it does not discover NSE opportunities.
- STATICALLY_CONFIRMED: `scanForSignals` deliberately emits `score: null` because a Boolean entry condition has no strength.
- STATICALLY_CONFIRMED: the official NSE master contains 3,314 current listings in the owner database.
- OBSERVED: only a small subset has stored price history; full-universe ranking is not currently supportable.
- STATICALLY_CONFIRMED: trend, RVOL, momentum, ATR, and traded-value features exist.
- STATICALLY_CONFIRMED: spread, corporate catalysts, India VIX, and sector context are unavailable.
- STATICALLY_CONFIRMED: risk, validation, forward, and paper ledgers exist and must remain authoritative.
- STATICALLY_CONFIRMED: `/brain` is already the operational cockpit but has no daily scan brief.

## Missing Layer

- Full-universe deterministic scan service.
- Durable scan run and candidate evidence.
- Reconciled funnel and named exclusion buckets.
- Ledger-derived Daily Market Decision Brief.
- Measured workload evidence that would justify dynamic model workers.

## Safety Reality

The first scanner slice must not call an LLM, spend a trial, access a holdout, activate a challenger, enroll paper capital, or place any order.
